Đưa lên GitHub Pages

  1. Tạo Repository mới công khai (Public) trên GitHub.
  2. Tạo file mới đặt tên index.html và dán toàn bộ mã nguồn này vào.
  3. Vào tab Settings của Repository -> chọn mục Pages.
  4. Ở mục Build and deployment, chọn nguồn là Deploy from a branch (Branch: main / root).
  5. Nhấn Save và chờ khoảng 1 phút là có link chạy trên Safari iPhone!
