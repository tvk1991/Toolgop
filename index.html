Hướng dẫn Úp GitHub Pages

  1. Nhấn nút "Tải file index.html" phía dưới để tải file mã nguồn về máy.
  2. Truy cập GitHub.com và tạo một Repository mới (chọn chế độ Public).
  3. Nhấn Add file -> Upload files và tải file index.html lên, sau đó nhấn Commit changes.
  4. Vào tab Settings của Repository -> chọn mục Pages ở cột bên trái.
  5. Tại mục Branch, chọn nhánh main và thư mục / (root) rồi nhấn Save.
  6. Chờ 1 phút và mở đường link GitHub Pages trên Safari iPhone!
